# ActivaTuPerfil CV Pro 🚀

**ActivaTuPerfil CV Pro** es una Skill diseñada para transformar información laboral dispersa en un currículum profesional, pulido y compatible con sistemas ATS (Applicant Tracking Systems), listo para descargar en formato `.docx` editable.

## 🎯 Características Principales
- **Cero invenciones:** Garantiza que ningún dato, fecha o logro sea inventado.
- **Optimización ATS:** Estructuras y formatos limpios que facilitan la lectura automatizada.
- **Redacción de alto impacto:** Utiliza verbos de acción y vocabulario profesional.
- **Generación en DOCX:** Exporta documentos 100% editables en Microsoft Word.
- **Adaptación a vacantes:** Analiza ofertas de empleo y destaca la experiencia relevante del usuario.

## 📦 Contenido del Paquete
- `SKILL.md`: Prompts y directrices de comportamiento para el LLM.
- `scripts/generate_docx.py`: Script generador de documentos Word profesionales.

## 💡 Modo de Uso
Sube esta Skill a tu plataforma compatible y pídele:
> *"Ayúdame a crear mi CV para un puesto de Analista de Datos a partir de esta experiencia..."*
